# 4. Dual-Asset Tokenomics ($LPUSD & $LBASE)

The LiquidaExchange ecosystem utilizes a robust dual-token model to separate transactional utility from protocol governance and value accrual.

| Token Name | Ticker | Primary Function | Supply Model |
| :--- | :--- | :--- | :--- |
| **Liquid Peso USD** | $LPUSD | USD-pegged stablecoin for daily student micro-savings, hedging, and P2P payments. | Elastic Supply (Reserve Backed) |
| **Liquid Base** | $LBASE | Protocol governance, fee distribution, staking rewards, and student ecosystem incentives. | 100,000,000 Fixed Cap |

## 4.1 $LBASE Token Distribution & Allocation
* **Student Community Airdrops & Rewards (40% - 40,000,000 $LBASE):** Reserved for active student adopters, campus savings clubs, and educational milestone achievements.
* **Liquidity Reserves (25% - 25,000,000 $LBASE):** Deployed to bootstrap deep liquidity pools across decentralized exchanges and P2P routing layers.
* **Solo Developer & Core Contributor (20% - 20,000,000 $LBASE):** Allocated to lead architect Rogelio Patricio Jr., bound by a strict 36-month linear vesting schedule with a 6-month cliff.
* **DAO Treasury & Security Grants (15% - 15,000,000 $LBASE):** Dedicated to third-party smart contract audits, legal compliance, and developer ecosystem grants.
